Strata MTP repair: before/after (IQ3_XXS and Q2_0 share the same drafter weights)
=================================================================================
Engine: Strata 0.1.28, Qwen3.8-Flash-Next GSQ-RCO, RTX 5090 Laptop 24GB + 64GB RAM

Root cause: 20 of 31 mtp.* tensor files fetched via HTTP Range were actually the
beginning of their safetensors shard (JSON header + unrelated data) because some
responses ignored the Range header and returned 200 with the whole file; the tool
kept the first n_bytes. The manifest sha256 (over downloaded bytes) cannot catch this.

Detection: a genuine tensor's raw file does not start with [u64 header_len][b'{"'].
